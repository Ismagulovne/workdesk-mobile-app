✅ **Можно запустить в 1 клик**

## 📋 ШАГ 1: Подготовка

### Убедись, что у тебя есть:
1. ✅ Репозиторий на GitHub
2. ✅ Файл `.github/workflows/build_release.yml` (уже создан)
3. ✅ Доступ к GitHub Actions (обычно включен по умолчанию)

---

## 🎯 ШАГ 2: Запуск сборки вручную

### Способ 1️⃣: Через GitHub UI (Самый простой)

1. Перейди на GitHub репозиторий WorkDesk
2. Нажми вкладку **Actions** (вверху страницы)
3. Найди workflow **"🚀 Build Release APK & AAB"** слева
4. Нажми **"Run workflow"** (выпадающее меню справа)
5. Нажми зелёную кнопку **"Run workflow"**
6. ⏳ Жди (сборка займёт 5-10 минут)

### Способ 2️⃣: Через теги (Автоматический запуск)

```bash
cd WorkDeskApp
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions **автоматически** запустится при создании тега!

---

## 📥 ШАГ 3: Скачивание файлов

### Когда сборка завершена:

1. Вернись на GitHub
2. Перейди в **Actions**
3. Нажми на последний запуск (должно быть зелёная галочка ✅)
4. Прокрутись вниз до **"Artifacts"**
5. Скачай:
   - 📦 `workdesk-apk` (APK файл)
   - 📦 `workdesk-aab` (AAB файл)

---

## 🔧 ШАГ 4: Загрузка в Google Play Console

### Загрузка AAB файла:

1. **Открой Google Play Console**
   - Перейди в **Тестирование и выпуск** → **Рабочая версия**
   
2. **Нажми "Создать выпуск"**
   
3. **Загрузи AAB файл**
   - Перетащи файл `app-release.aab` в область загрузки
   
4. **Заполни примечания к выпуску:**
   ```
   Версия 1.0.0

   Первый релиз WorkDesk!

   ✨ Возможности:
   - Отслеживание рабочего времени
   - Управление задачами
   - Удалённый доступ к устройствам
   - Синхронизация с Active Directory
   - Аналитика и отчёты
   ```

5. **Сохрани черновик** (или отправь на проверку, если всё готово)

## 🆘 РЕШЕНИЕ ПРОБЛЕМ

### Ошибка: "workflow is not enabled"

**Решение:**
1. Перейди в **Settings** (репозитория)
2. Перейди в **Actions** → **General**
3. Выбери **"Allow all actions and reusable workflows"**
4. Сохрани

### Ошибка: "flutter: command not found"

**Решение:**
- Это невозможно, если используется GitHub Actions
- Проверь, что workflow файл находится в `.github/workflows/`

### Сборка очень долгая (> 15 минут)

**Это нормально!** Первая сборка долгая (нужно скачивать Flutter, кэш и т.д.)
