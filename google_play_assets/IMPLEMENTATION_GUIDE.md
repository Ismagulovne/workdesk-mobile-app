## 📝 ИНСТРУКЦИИ ПО ЗАПОЛНЕНИЮ

### 1️⃣ ЗАПОЛНЕНИЕ ОПИСАНИЯ В GOOGLE PLAY CONSOLE

Перейди в **Store Listing** или **Store presence** в боковом меню приложения и заполни:

**Краткое название (Short description - 50 символов):**
```
Управление рабочим временем
```

**Описание (Full description - 4000 символов):**
Используй текст из `store_listing_content.md`

**Категория:**
```
Productivity (Производительность)
```

**Контактный email:**
```
info@worktime.kz
```

**Политика конфиденциальности:**
```
https://worktime.kz/privacy
```

**Сайт приложения:**
```
https://worktime.kz
```

---

### 2️⃣ ЗАГРУЗКА СКРИНШОТОВ

Требования к скриншотам:
- **Размер**: 1080×1920 px или 1440×2560 px
- **Формат**: PNG или JPEG
- **Количество**: минимум 2, максимум 8
- **Язык**: на русском и английском (опционально)

**Что показать на скриншотах:**
1. 📊 Главный экран / Dashboard
2. ⏱️ Отслеживание времени
3. 📋 Список задач
4. 📈 Отчёты и статистика
5. ⚙️ Параметры и настройки

**Советы:**
- Используй реальные данные приложения
- Добавь текст/стрелки для выделения ключевых функций
- Убедись, что текст читаемый на экране телефона

---

### 3️⃣ ЗАГРУЗКА ИКОНКИ ПРИЛОЖЕНИЯ

**Требования:**
- **Размер**: 512×512 px
- **Формат**: PNG с прозрачностью
- **Вес**: < 1 MB
- **Содержание**: логотип должен быть узнаваемым

**Рекомендации:**
- Используй цвета из бренда WorkTime (фиолетовый #667eea)
- Не добавляй текст
- Убедись, что иконка видна на малых размерах (48px)

---

### 4️⃣ ЗАГРУЗКА FEATURE GRAPHIC

**Требования:**
- **Размер**: 1024×500 px
- **Формат**: PNG или JPG
- **Вес**: < 15 MB
- **Назначение**: показывается на странице приложения в магазине

**Содержание:**
- Название приложения "WorkDesk"
- Краткое описание функции
- Привлекательный визуальный дизайн
- Цветовая гармония с иконкой

---

### 5️⃣ КОНТЕНТНОЕ РЕЙТИРОВАНИЕ (IARC)

**Путь в Google Play Console:**
1. Store Listing → Контентное рейтирование
2. Нажми "Пройти анкету контентного рейтирования"
3. Ответь на вопросы о содержании приложения:
   - Есть ли насилие? НЕТ
   - Есть ли нецензурный контент? НЕТ
   - Есть ли сексуальный контент? НЕТ
   - Есть ли алкоголь/табак? НЕТ
   - Есть ли азартные игры? НЕТ
   - Есть ли опасный контент? НЕТ
4. Отправь анкету
5. Получи IARC рейтинг

---

### 6️⃣ ЗАГРУЗКА APK/AAB

После сборки APK/AAB файла:

1. **Перейди в** Тестирование и выпуск → Рабочая версия
2. **Нажми** "Создать выпуск"
3. **Загрузи** APK или AAB файл
4. **Заполни** примечания к выпуску (Release notes):
   ```
   Версия 1.0.0

   Первый релиз WorkDesk!

   ✨ Возможности:
   - Отслеживание рабочего времени
   - Управление задачами
   - Удалённый доступ к устройствам
   - Синхронизация с Active Directory
   - Аналитика и отчёты
   ```
5. **Сохрани** черновик
